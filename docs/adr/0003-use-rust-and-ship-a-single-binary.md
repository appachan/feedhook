# 3. Use Rust and ship a single binary

Date: 2026-09-27

## Status

Accepted

## Context

feedhook は Rust で実装する。動かすサーバーには、言語のランタイムやパッケージマネージャーを入れずに済ませたい。開発環境では、ツールチェーンのバージョンを揃えたい。

## Decision

- サーバーには単一の実行ファイルを置くだけで動くようにする
- ツールチェーンは mise で管理し、バージョンはリポジトリの `mise.toml` で固定する
- Linux 向けのビルド方法(musl による静的リンク、クロスコンパイルかサーバー上でのビルドか)は、デプロイのときに別の ADR で決める

## Consequences

- サーバー側にランタイムが要らず、配置と更新はファイルの置き換えで済む
- ツールチェーンを上げるときは `mise.toml` を変更する
